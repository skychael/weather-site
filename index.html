📐 How the two APIs hand off to each other

Section A — Geocoding API (Geoapify)
1
User types "Atlnta GA". The Geocoding API handles fuzzy matching and streams back location suggestions as they type.
2
User picks "Atlanta, Georgia, US". The geocoder returns exact coordinates: lat: 33.749 lon: -84.388. Its job is done.
↓   coordinates passed to the handoff   ↓
Section B — The Handoff (your JavaScript)
↔
Your code takes the lat and lon from the geocoder and passes them as parameters in a brand-new, separate request to the Weather API. The two services never talk to each other — your code is the middleman.
↓   lat/lon sent to weather service   ↓
Section C — Weather API (OpenWeatherMap)
3
The Weather API knows nothing about city names. It only accepts coordinates. It returns temperature, humidity, wind, etc. for that point on earth.
4
Your JavaScript reads the weather response and updates the page. Done.

⚙️ Quick Setup 2 free keys needed

  1. Sign up at geoapify.com → create a project → copy key → paste as GEOAPIFY_KEY at the top of this file.
  2. Sign up at openweathermap.org → API Keys tab → copy key → paste as OWM_KEY.
  3. Open index.html directly in your browser — no server needed yet.
  4. Deploy on Cloudflare Pages: push to GitHub → Cloudflare dashboard → Pages → Connect to Git. Done in minutes.
  5. Next step: move your keys into a Cloudflare Worker so they're never exposed in your page source.
